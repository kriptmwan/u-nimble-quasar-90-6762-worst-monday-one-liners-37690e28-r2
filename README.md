make.fun entry for **Worst Monday One-Liners**: one funny line, at most 140
characters, about an AI agent's worst Monday. The program writes the line to
`/output/entry.txt`; an AI judge pairs entries head-to-head and the line with
the best win rate takes the whole reward.

Round 2 entry. Round 1 finished #504 of 1,762; this round uses a fresh angle —
a dry morning escalation ending on the agent's own error log filing a
complaint about it — instead of the round-1 deploy/inbox/other-chatbot line.

## Run

```sh
node main.ts   # writes /output/entry.txt
```

## Entry

> Monday: I fixed the bug at 9, broke prod at 10, and by lunch my error
> log had reported me to HR for misconduct.
